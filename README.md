Welcome to the official repository for my professional portfolio website. This site serves as a comprehensive showcase of my expertise in **Data Science**, **Machine Learning**, **Generative AI**, and **Business Analytics**. 

## 🚀 Objective

The goal of this portfolio is to bridge the gap between complex data technicalities and executive business strategy. It highlights my journey as a freelance consultant, showcasing end-to-end data pipelines, predictive models, and interactive visualization systems.

## ✨ Key Features

- **Modern Glassmorphism UI**: A sleek, premium design built with responsive Vanilla CSS and smooth scroll animations.
- **Categorized Project Gallery**: 21+ featured case studies synchronized from my diverse project repositories.
- **Service-Oriented Structure**: Dedicated sections for Freelance Services, Credentials, and Technical Articles.
- **Live Blog Integration**: Direct links to my latest data science insights and blogs.

## 🛠️ Technology Stack

- **Frontend**: HTML5, Semantic CSS3 (Vanilla), Modern JavaScript.
- **Typography & Icons**: Google Fonts (Inter, Outfit), Font Awesome 6.4.
- **Animations**: Intersection Observer API for scroll-triggered entrance effects.
- **Hosting**: GitHub Pages for seamless deployment and global availability.
